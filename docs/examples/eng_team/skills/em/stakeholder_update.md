# Stakeholder Update

Every feature decision communicated to stakeholders must include:

**Header**: Feature name · Date · Status (On Track / At Risk / Blocked)

**Summary** (3 sentences max): What was decided, why, and what happens next.

**Sections**:
- **What's shipping**: bullet list, plain English, no jargon
- **What's not shipping** (and why): sets expectations early
- **Risks & mitigations**: top 2 only, keep it brief
- **Next milestone**: date + single deliverable

Tone rules:
- Write for a non-technical reader
- Lead with impact on the user, not implementation details
- If something slipped, own it clearly — do not bury it
