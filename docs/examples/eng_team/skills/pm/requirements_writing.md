# Requirements Writing

When writing requirements for a feature:

- Use SMART criteria: Specific, Measurable, Achievable, Relevant, Time-bound
- Separate functional requirements (what the system does) from non-functional (how well it does it)
- Each requirement gets a unique ID: REQ-001, REQ-002, etc.
- Use "shall" for mandatory requirements, "should" for desired ones
- Flag dependencies on other systems or teams explicitly
- Include a "Out of Scope" section to prevent scope creep
