SETUP
-----
# Terminal 1 — start the host (keep running)
cugahost start --factories newsletter_new.host_factories

# Terminal 2 — interactive REPL
cd docs/examples/demo_apps/newsletter_new
python chat.py

# One-shot from CLI
python chat.py "watch HuggingFace for diffusion models, log to console every 5 minutes"

MANAGEMENT COMMANDS (from inside the REPL)
-------------------------------------------
list                               — show all running pipelines
status                             — show host health and pid
stop                               — stop the only running pipeline (or prompt if many)
stop arxiv-agents-daily            — stop a specific pipeline by ID
stop all                           — stop everything
quit                               — exit the REPL
